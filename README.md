# Student Deadline and Academic Overload Tracker

A DBMS micro project (Vel Tech, Database Management Systems course) that stores students, courses, assignments and faculty, and detects students with more than 15 pending workload hours.

## What's inside

- `schema_and_data.sql`: MySQL table creation and sample data
- `queries.sql`: joins, nested queries, update and delete examples, overload detection
- `mongodb_queries.js`: MongoDB document model and queries
- `neo4j_queries.cypher`: Neo4j graph model and Cypher queries

## Highlights

- ER model and relational schema (Student, Course, Student_Course, Assignment, Faculty) with primary and foreign keys
- Normalization up to 3NF
- The same overload query implemented in MySQL, MongoDB and Neo4j (result: Arun, 18 workload hours)
